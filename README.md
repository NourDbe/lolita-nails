# Lolita Nails — Laravel CMS Edition

موقع Laravel 12 متكامل لـ Lolita Nails مع واجهة حجز ولوحة إدارة CMS لإدارة محتوى الموقع بدون تعديل الكود.

## ما الذي يمكن للأدمن التحكم به؟

- المواعيد: البحث، الفلترة، تغيير الحالة، الحذف.
- الخدمات: الاسم، الوصف، السعر، المدة، الصورة، الترتيب، إظهار/إخفاء.
- معرض الصور: رفع الصور، التصنيف، الترتيب، صورة مميزة، تعديل وحذف.
- Reels: رفع فيديو MP4/MOV/WebM حتى 50MB، Poster اختياري، العنوان، الترتيب، نشر/إخفاء، تعديل وحذف.
- التقييمات: إضافة وتعديل وحذف وتحديد عدد النجوم والنشر.
- الدوام: ساعات العمل لكل يوم وأيام الإجازات الخاصة.
- إعدادات الموقع: عنوان الـHero، الوصف، الموقع، الهاتف، WhatsApp، Instagram، عدد المتابعين، سياسة الحجز، SEO.
- إظهار/إخفاء أقسام Gallery / Reels / Reviews / Before-After.
- Dashboard للمواعيد والإحصائيات والإيراد المتوقع والخدمات الأكثر طلباً.

> الهوية الأساسية والكود والـCSS محمية ولا يتم تعديلها من الـCMS حتى لا ينكسر التصميم.

## تشغيل المشروع

المتطلبات: PHP 8.2+، Composer، وSQLite أو MySQL.

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

افتح:

- الموقع: `http://127.0.0.1:8000`
- لوحة الإدارة: `http://127.0.0.1:8000/admin/login`

### بيانات الإدارة التجريبية

- Email: `admin@lolita.local`
- Password: `Lolita123!`

غيّري كلمة المرور قبل النشر الفعلي.

## قاعدة البيانات

الإعداد الافتراضي مناسب لـ SQLite. لاستخدام MySQL عدّلي إعدادات `DB_*` في `.env` ثم شغلي:

```bash
php artisan migrate --seed
```

## رفع الصور والريلز

الملفات التي يرفعها الأدمن تحفظ على `public` disk داخل `storage/app/public` وتظهر عن طريق `public/storage`، لذلك يجب تنفيذ:

```bash
php artisan storage:link
```

عند النشر تأكدي أن `storage` و `bootstrap/cache` قابلان للكتابة.

## ملاحظات قبل تسليم الموقع

- الأسعار الحالية Demo ويمكن تعديلها بالكامل من لوحة الإدارة.
- التقييمات الحالية Demo ويُنصح باستبدالها بتقييمات موثقة.
- الريلز الثلاثة الحالية مضمنة كبيانات أولية ويمكن حذفها أو استبدالها من لوحة الإدارة بعد التشغيل.
- بيانات التواصل قابلة للتعديل من صفحة **إعدادات الموقع**.
